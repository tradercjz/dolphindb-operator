💡 DolphinDB Kubernetes 许可证管理操作指南

1. 首次申请与获取 License 点击上方“一键复制指纹清单”，直接发送给 DolphinDB 官方商务团队。官方将针对各节点的主机名及 Machine-ID 签发对应的商业版 dolphindb.lic。
2. 在线更新与云原生 Secret 通过页面“上传 / 更新 License”功能，将官方签发的许可证直接存入 Kubernetes Secret (dolphindb-license)，无需逐台 SSH 登录物理机，云原生全自动同步。
3. 零停机免重启热加载 许可证更新后，点击“免重启热加载”，系统自动向集群各控制器与数据节点广播 updateLicense()，新配额与到期时间秒级生效，生产业务零中断！

旧版 K8s 套件平滑升级工作台 (Legacy Migration Toolchain)

自动探测 Kubernetes 集群中基于 dolphindbs.dolphindb.dolphindb.io/v1 的存量旧集群，提供深度兼容性体检预检、配置参数提取、双轨蓝绿平滑迁移以及存量 PVC 原地接管向导。
方案 A：强烈推荐 双轨蓝绿平滑迁移 (Blue-Green)
在同集群并行部署全新云原生集群，利用 DolphinDB 原生分布式工具进行全量与增量同步，业务灰度切流，业务 0 停机、零风险随时可回滚！
⏱️ 停机时间: 0 停机 🛡️ 风险评级: 极低 (无历史包袱) 📦 适用: 中小数据量 (TB 级内)
方案 B：海量数据专用 存量 PVC 原地安全接管 (In-Place Adoption)
通过 --cascade=orphan 孤儿化解除旧版 StatefulSet 强级联绑定，原位复用 Longhorn/本地 NVMe 数据卷，由新 Operator 轻量换壳接管。
⏱️ 停机时间: 3~8 分钟快速换壳 🛡️ 风险评级: 可控 (严格刷盘) 📦 适用: 超大海量数据 (免搬迁)
